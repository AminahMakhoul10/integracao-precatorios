# Análise do case de integração

Requer Python 3.10+. Execute na pasta do projeto:

    python limpar_case.py --input dados --output saida

O programa preserva as entradas e grava precatorios.json, pagamentos.json e relatorio.json. Divergências incertas ficam para revisão.

## IA

Usei IA para estruturar a análise e revisar o código. Conferi conclusões contra os arquivos entregues e validei normalização, deduplicação e estorno com testes automatizados. Ambiguidades foram documentadas como dúvidas.
